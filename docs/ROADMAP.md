# Britain: Underworld — Roadmap

An original multiplayer-first British open-world crime game. Independent of IrisKey.ai.

## Phase 0: Local multiplayer proof
- [ ] Launch the Godot project on macOS
- [ ] Host a local session
- [ ] Join from a second game instance
- [ ] Confirm connection and disconnect handling
- [ ] Test police/criminal role selection

## Phase 1: Playable vertical slice
- [ ] Small fictional Coventry-inspired street
- [ ] Two visible networked player characters
- [ ] Server-validated movement and role state
- [ ] One drivable vehicle
- [ ] Basic robbery and pursuit loop

## Later phases
- Expand to Solihull and Birmingham
- Garages, housing, businesses and vehicle customisation
- Age-appropriate social and dating features, with no sexual player interactions
- NVIDIA NIM experiment for NPC dialogue behind a server-side gateway
- Anti-cheat, moderation, load testing and Android feasibility

## Security and licensing
Keep API keys out of Git. Review all third-party code and asset licences before reuse. Do not connect this project to IrisKey.ai infrastructure or patents.
